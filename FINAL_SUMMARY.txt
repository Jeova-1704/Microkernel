🏗️ PADRÕES ARQUITETURAIS E DE PROJETO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ARQUITETURA:
  ✓ Microkernel (Plugin Architecture) - Padrão principal
  ✓ Layered Architecture (API → Core → Plugins)
  ✓ Client-Server Architecture

PADRÕES DE PROJETO:
  ✓ Strategy Pattern (Plugins intercambiáveis)
  ✓ Registry Pattern (Plugin Manager)
  ✓ Template Method (BaseMediaPlugin)
  ✓ Facade Pattern (API simplifica complexidade)
  ✓ Dependency Injection (Inversão de dependências)
  ✓ Abstract Factory (Criação de plugins)

PRINCÍPIOS SOLID:
  ✓ Single Responsibility - Cada classe uma responsabilidade
  ✓ Open/Closed - Aberto para extensão, fechado para modificação
  ✓ Liskov Substitution - Plugins substituíveis
  ✓ Interface Segregation - Interfaces mínimas
  ✓ Dependency Inversion - Depende de abstrações

📡 API REST - 10 ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GET    /api/                       → Informações do sistema
  GET    /api/plugins                → Lista plugins registrados
  GET    /api/formats                → Formatos suportados
  POST   /api/upload                 → Upload de arquivo
  GET    /api/media                  → Lista arquivos
  GET    /api/media/{filename}/analyze     → Analisa arquivo
  GET    /api/media/{filename}/validate    → Valida arquivo
  GET    /api/media/stream/{filename}      → Stream de mídia
  DELETE /api/media/{filename}       → Remove arquivo
  GET    /api/health                 → Health check

🚀 COMO EXECUTAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BACKEND (Terminal 1):
   cd backend
   python -m venv venv
   venv\Scripts\activate              # Windows
   # source venv/bin/activate         # Linux/Mac
   pip install -r requirements.txt
   python main.py

   ✅ Rodando em: http://localhost:8000
   📖 Docs: http://localhost:8000/docs

2. FRONTEND (Terminal 2):
   cd frontend
   npm install
   npm run dev

   ✅ Rodando em: http://localhost:3000

3. ACESSAR:
   🌐 Aplicação: http://localhost:3000
   📡 API: http://localhost:8000/api
   📖 Swagger: http://localhost:8000/docs
